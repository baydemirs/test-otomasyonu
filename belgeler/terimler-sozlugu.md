# Terimler Sözlüğü

| Terim | Bu projedeki anlamı |
| --- | --- |
| Mimari | Hangi parçanın ne yapacağı ve parçaların nasıl birlikte çalışacağı |
| AI ajanı | Görevi yerine getirmek için dosya okuma, kod yazma veya komut çalıştırma araçlarını kullanabilen yapay zekâ sistemi |
| AGENTS.md | Projeyi devralan geliştirme ajanı için çalışma talimatlarını taşıyan dosya |
| Markdown ve .md | Başlık, liste ve bağlantı içeren düz metin belge biçimi |
| İş akışı | Görevi seçme, uygulama, kontrol etme ve sonucu kaydetme sırası |
| Test otomasyonu | Uygulamada işlemleri yapıp gerçekleşen sonucu beklentiyle karşılaştıran kod |
| Kabul kriteri | İşin hangi durumda tamamlanmış sayılacağını belirleyen açık koşul |
| Bağlantı katmanı veya adaptör | Test kodunun hedef uygulamayı kontrol etmesini ve sonuç okumasını sağlayan bölüm |
| YAML | Görev durumu gibi kayıtların insanlar ve programlar tarafından okunabildiği metin biçimi |
| Git | Dosya değişikliklerinin sürümlerini ve geçmişini takip eden araç |
| Deterministik kontrol | Aynı girdilere aynı kuralları uygulayan kontrol. Ortam değişirse sonuç da değişebilir |
| RAG | İhtiyaç duyulan bilgiyi bir belge havuzundan bulup yapay zekâya sunma yaklaşımı |

Bu terimleri baştan ezberlemek gerekmiyor. İlk görev uygulamayı tanımaktır. Bir araç veya kavram kullanılacağı zaman ne işe yaradığı ve niçin gerektiği açıklanacak.

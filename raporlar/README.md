# Sonuçlar ve Kanıtlar

[Uygulama incelemesi](uygulama-incelemesi.md) statik bulguları, [paket doğrulaması](paket-dogrulama.md) geliştirme ortamında yapılan kontrolleri tutar. Windows çıktıları kosular/ altında her çalıştırmaya ayrı kimlikle yazılır. Eski raporun üzerine yazılmaz.

Arayüz envanteri bir test sonucu değildir. Gerçek uygulama testleri GOREV-001'de eklenecek. Kayıt alanları [doğrulama kriterlerine](../belgeler/dogrulama-kriterleri.md) uygun olacak.

Herkese açık GitHub deposu yalnız özet raporları içerir. `kosular/` altındaki ham kayıtlar yerel çalışma alanında kalır; görev kaydındaki geçmiş kanıt yolları yeni klonda otomatik olarak doğrulanamaz.
